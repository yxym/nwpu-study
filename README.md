#西北工业大学课程资料

> 本仓库包含西北工业大学本科课程的学习资料、实验报告、课件等。

## 资料列表

### 大一上学期
- **工程化学**: 课件、复习资料、实验报告
- **工程材料**: 实验报告、海报
- **科英**: presentation、case study
- **计算方法**: 课件、习题
- **高等数学**: 复习资料

### 大二下学期
- **材料学实验2**: 实验指导、实验报告、原始数据
  - EXP-2-1: 弹性体材料实验
  - EXP-2-2: 不确定度分析
  - EXP-2-3: 柔性传感器
  - EXP-2-4: 橡胶材料
- **工程力学**: 实验报告、poster
- **热力学与相变**: 课件、习题答案、复习资料
- **毛概**: 复习资料、实践报告
- **大学美育**: 课程作业

## 使用说明

1. **克隆仓库**
   ```bash
   git clone https://github.com/yxym/nwpu-study.git
   ```

2. **安装 Git LFS**（大文件支持）
   ```bash
   brew install git-lfs
   git lfs install
   ```

3. **更新资料**
   ```bash
   git pull origin main
   ```

## 注意事项

- 部分大文件使用 [Git LFS](https://git-lfs.github.com) 存储
- 资料仅供学习参考，请遵守学校相关规定
- 欢迎提交 Pull Request 补充资料
